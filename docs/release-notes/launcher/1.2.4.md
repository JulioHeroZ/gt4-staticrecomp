# GT4Recomp 1.2.4-rc1

**Earn RetroAchievements while playing Gran Turismo 4 USA v2.00.**

## New

- Sign in and see your achievement progress in Settings > Achievements.
- Get in-game notifications when you earn achievements.
- Choose Hardcore mode or replay earned achievements with Encore mode.

## Fixes

- An old account refresh can no longer undo sign-out or newer options.
- Closing the game cancels pending achievement network requests.

## Good to know

- This update supports the original USA v2.00 game; Spec II support remains separate.
- The launcher interface remains in English for this update.

- Test candidate: install the final 1.2.4 manually when it becomes available.
